### top 10 to study first

1. rauno.me — the tightest example of Apple-grade interface detail on a personal site; motion is nearly invisible and every state is considered.
2. paco.me — proves how far typographic scale, spacing and easing alone can carry a boring personal site.
3. brittanychiang.com — the canonical restrained developer portfolio: dark palette, one accent, almost no motion.
4. craigmod.com — best-in-class reading experience; long-form typography and image pacing without any framework noise.
5. rsms.me — Inter's author; fast, quiet, and a masterclass in type metrics and optical sizing.
6. emilkowalski.com — micro-interaction craft explained and demonstrated; the closest thing to a written spec for Apple-grade UI.
7. frankchimero.com — the reference for editorial essay layout and whitespace discipline.
8. sive.rs — radical minimalism: no images, tiny pages, near-instant loads. The floor for "boring".
9. brianlovin.com — dense personal site that still feels calm; good model for a project/notes architecture.
10. immersive-g.com — the motion ceiling to aspire to later: WebGL scroll choreography done with restraint.

### coverage gaps

- Sidebar.io "top 5" roundups: no machine-readable index of outbound site URLs; the newsletter archive was not harvestable, so 0 entries were sourced from it.
- land-book.com: returns HTTP 403 to this client on every path tried (/, /websites, /sites); not harvested.
- siteinspire.com: returns HTTP 429 (rate limited) to this client; not harvested.
- Godly.website (now recent.design): fully client-rendered; /rss and /websites return the app shell with no static outbound links, so 0 URLs could be extracted.
- One Page Love: its official API needs an API key, so the public gallery + detail pages were used instead (48 live URLs extracted, 17 selected).
- Olivia Ng (the designer) has no verifiable portfolio domain. oliviang.com resolves but is "OLIVIA NG BRIDAL", an unrelated retailer, so it was dropped rather than miscounted.
- The brief's "Lynx" could not be disambiguated to a single live portfolio domain; nothing was invented to fill it.
- Awwwards paginated listings (/websites/?page=N) are robots-disallowed, so only non-query listing endpoints were harvested (portfolio, sites of the day, honors, agency-studio, freelance, typography, art & illustration, e-commerce).
- Dropped after verification: areaofpractice.com, bureau-borsche.com, cameronmoll.com, dannpetty.com, subtraction.com, wichary.com and www.colosse.site (all failed HEAD and GET repeatedly; two had no DNS at all).
- Dropped as low-value despite returning 200: echofreelance.com (parked domain notice), marina-zakharova.netlify.app (boilerplate starter page), gchf.kr/index.html (a festival site, off-brief), michaelnielsen.org (DreamHost placeholder page).
