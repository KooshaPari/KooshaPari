## Lighthouse

**Status: NOT RUN.**

- Lighthouse CLI 13.4.1 is installed at
  `/opt/homebrew/bin/lighthouse`.
- A Chrome browser binary is required to actually
  run audits. None is present on this host:
  - No system Chrome / Chromium / Brave
  - No `puppeteer` / `playwright` in `node_modules`
  - No bundled headless shell in `puppeteer` cache
- Disk: 28 GB free of 926 GB (97% used); a
  full Chrome download (~150 MB) would fit, but
  the operator has not authorized installing a
  browser binary unilaterally.
- The 07 doc section H already flagged Lighthouse
  as a known gap.

**Required to close the publication proof:**
- Either install a Chrome binary (operator action
  via `npx puppeteer browsers install chrome` or
  `brew install --cask google-chrome`)
- Or redefine the close criteria to skip Lighthouse
  (a STATE.md amendment, not a doc-only edit)
